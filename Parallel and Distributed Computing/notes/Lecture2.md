# Cloud Computing
**Definition:** Cloud computing is the practice of storing, managing, and processing data on remote servers over the internet instead of using local computers.Instead of running programs on your PC or machine, they run on remote servers called cloud server.

- Cloud computing allows user to access applications and dara from anywhere through the internet.
Real-life Examples:
- Google Drive
- Dropbox
- Netflix
- Gmail
# Why Cloud Computing is Used:
1.Pay as You Go:
User pay only for the resources they use.  
Example:  
A startup pays only for the cloud storage it currently needs.  
2.24/7 Availability:
Cloud services are available anytime.  
Example:  
Students can access Google Drive from home, university, or mobile phone.  
3.Device and Location Independent:  
You can access data from any device connected to the internet.  
Example:  
You upload a document from your laptop and later open it on your Phone.  
4.Easy Deployment:  
Companies can quickly deploy applications without buying expensive hardware.  
Example:  
A company can launch a website in minutes using cloud hosting.  
5.Scalability:  
Cloud system can increase or decrease resources depending on demand.  
Example:  
During big online sales like Black Friday, e-commerce websites need more computing power.  
Cloud servers automatically scale up.  
# Evolution of Cloud Computing:
Cloud computing evolved from earlier technologies such as:  
- Distributed computing
- Grid computing
- Utility computing
- Virtualization
- Web hosting  
these technologies gradually led to modern cloud platforms.   

# Key Enabling Technologies:
Several technologies made cloud computing possible.
1.High-Speed Internet:  
Fast broadband connections allow quick data transfer.  
Example:  
Streaming movies on Netflix requires high-speed internet.  
2.Powerful Servers:  
Modern servers can handle large numbers of users simultaneously.  
Example:  
Facebook servers handle billions of user requests.
3.Virtualization:  
Virtualization allows one physical server to run multiple virtual machines.  
This improves efficiency and reduces cost.  
Example:  
A single physical server may run:
- 10 virtual servers
- Each serving different applications
# Five Essentail Characteristics of Cloud Computing
1.On-Demand Self Service: Users can access resources whenever needed without human interaction.  
Example:A developer can instantly create a cloud server server from AWS.  
2.Broad Network Access:Cloud services are accessible through the internet.  
Example:Google Docs works on laptops, tablets, and phones.  
3.Resource Pooling:Cloud providers use a shared pool of resources to serve many users.  
Example:Thousands of customers share the same Amazon cloud infrastructure.
4.Rapid Elasticity:Resources can quickly scale up or down depending on demand.  
Example:Video streaming services increase servers when millions watch a live event.  
5.Measured Service(Pay per User):User are charged based on how much they use.  
Example:Paying for cloud storage based on GB used.

- Services Model

# Types of Cloud Deployment Models:
Deployment models define how cloud infrastucture is used.
1.Public Cloud:Public clouds are owned by Third-party providers and available to the public.  
Example:Amazon Web Services(AWS)  
Companies rent computing resources from cloud providers.
2.Private Cloud:Private cloud is used by one organization only.  
Example:A bank may run its own private cloud for financial data.  
3.Hybrid Cloud:Hybrid cloud combines public cloud and private cloud.Some data is stored privately, while other services run on public cloud.  
Example:A hospital keeps patient records in a private cloud nut uses public cloud for website hosting.
